# Samples

**uci_transactions_sample.csv** is an actual 300-row, seed-42 excerpt of [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii), by Daqing Chen (DOI: 10.24432/C5CG6D), under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It does not replace the full source for published totals.

**grocery_transactions_demo.csv** is the original 30-row toy demo, kept separately. It contains no prices and is not the real Instacart dataset. The new pipeline does not use it.
